# AGENTS

## Cursor Cloud specific instructions

### What this is
React Native (**Expo SDK 57**, RN 0.86, React 19, TypeScript) Android app for
**Vizag Jobs** — a job portal for Visakhapatnam. It is a mobile replica of the
web app [`Kiran040595/vizag-jobs`](https://github.com/Kiran040595/vizag-jobs)
(`jobsinvizag.in`) and reuses that app's Supabase `jobs` data model + filtering
logic. Package manager is **npm** (`package-lock.json`). Standard commands live
in `package.json` (`web`, `android`, `ios`, `start`, `lint`, `typecheck`,
`test`, `setup`, `prebuild:android`, `build:apk`) — see there rather than
duplicating.

### Environment
- **JDK 21** is the system JDK (`JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64`).
  **Node 22 / npm 10** are available.
- **Android SDK** lives at `~/android-sdk` (`ANDROID_HOME`). Source
  `scripts/env.sh` before native builds, or run `npm run setup` to bootstrap
  everything (npm install + SDK packages + `expo prebuild`).
- The cloud update script runs `npm install` when `package.json` exists. SDK/JDK
  are not part of the update script — use `npm run setup` on first run if the
  SDK is missing.

### Running / demonstrating the app
- **No `/dev/kvm` in the cloud VM**, so a hardware-accelerated Android emulator
  cannot boot here. Demonstrate the UI with **`npm run web`** (react-native-web,
  serves on `http://localhost:8081`) — it renders the identical React Native
  components. Metro bundles JS lazily, so the first page load takes ~10-40s.
  Use a browser / computer-use to interact.
- `npm start` runs the Expo dev server (Expo Go / QR) for real devices.
- `npm run android` builds and installs on a connected USB device (requires
  `adb devices` to show a device).

### Building the Android app (APK)
- `android/` and `ios/` are **generated by prebuild and git-ignored** — never
  commit them. To (re)generate: `npm run prebuild:android`.
- Build a debug APK: `source scripts/env.sh && npm run build:apk`. Output:
  `android/app/build/outputs/apk/debug/app-debug.apk` (package
  `com.jobsinvizag.app`). The first build auto-downloads the `compileSdk`
  platform + build-tools via Gradle, which needs network access.

### Data / Supabase
- Defaults to the **production Vizag Jobs** Supabase project
  (`fbyyfyhdglcpkhxskffj`, same as jobsinvizag.in / web `VITE_SUPABASE_*`).
  `app.config.js` + `src/lib/supabaseCredentials.ts` ignore README placeholders
  like `<anon-key>` so a bad `.env` cannot override production. Use
  `npm run build:apk` to produce a sideloadable APK with env + JS embedded.
  On fetch failure the app falls back to bundled sample jobs
  (`src/data/sampleJobs.ts`) and shows a retry banner.

### Gotcha
- Metro caches transform errors: if you see a parse/syntax error whose code
  frame doesn't match the current file (e.g. after rapid edits), restart with
  `npx expo start --web --clear`.
