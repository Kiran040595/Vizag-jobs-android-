# AGENTS

## Cursor Cloud specific instructions

### What this is
React Native (**Expo SDK 57**, RN 0.86, React 19, TypeScript) Android app for
**Vizag Jobs** — a job portal for Visakhapatnam. It is a mobile replica of the
web app [`Kiran040595/vizag-jobs`](https://github.com/Kiran040595/vizag-jobs)
(`jobsinvizag.in`) and reuses that app's Supabase `jobs` data model + filtering
logic. Package manager is **npm** (`package-lock.json`). Standard commands live
in `package.json` (`web`, `android`, `ios`, `start`, `lint`, `typecheck`,
`test`) — see there rather than duplicating.

### Environment (already provisioned in the VM image)
- **Android SDK** at `~/android-sdk`; `ANDROID_HOME`/`ANDROID_SDK_ROOT` and
  `PATH` are exported from `~/.bashrc`. JDK 21 is the system JDK.
- A standalone Gradle 8.9 lives at `~/gradle` but is **not** needed for builds —
  the generated `android/` project ships its own `./gradlew`.
- The update script only runs `npm install`; the SDK/JDK are baked into the
  image, not the update script.

### Running / demonstrating the app
- **No `/dev/kvm` in the cloud VM**, so a hardware-accelerated Android emulator
  cannot boot here. Demonstrate the UI with **`npm run web`** (react-native-web,
  serves on `http://localhost:8081`) — it renders the identical React Native
  components. Use a browser / computer-use to interact.
- `npm start` runs the Expo dev server (Expo Go / QR) for real devices.

### Building the Android app (APK)
- `android/` and `ios/` are **generated by prebuild and git-ignored** — never
  commit them. To (re)generate: `npx expo prebuild --platform android`.
- Build a debug APK: `cd android && ./gradlew assembleDebug --no-daemon`
  (~6 min cold). Output: `android/app/build/outputs/apk/debug/app-debug.apk`
  (package `com.jobsinvizag.app`). The first build auto-downloads the
  `compileSdk` platform + build-tools via Gradle, which needs network access.

### Data / Supabase
- With no Supabase env vars the app shows **bundled sample Vizag jobs**
  (`src/data/sampleJobs.ts`) — it runs fully offline. To use live data, set
  `EXPO_PUBLIC_SUPABASE_URL` and `EXPO_PUBLIC_SUPABASE_ANON_KEY` (same values as
  the web app's `VITE_SUPABASE_*`), e.g. via `.env` or Cloud secrets.

### Gotcha
- Metro caches transform errors: if you see a parse/syntax error whose code
  frame doesn't match the current file (e.g. after rapid edits), restart with
  `npx expo start --web --clear`.
